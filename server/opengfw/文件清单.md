## 📄 文件说明

### 核心脚本

#### `deploy_opengfw.sh`
- **用途**: 自动化部署 OpenGFW
- **功能**:
  - ✅ 检测系统架构和依赖
  - ✅ 下载 OpenGFW 和 GeoIP 数据库
  - ✅ 交互式配置拦截规则
  - ✅ 创建 systemd 服务
  - ✅ 自动启动并验证
- **使用方法**:
  ```bash
  cd /root/lxd-toolkit/server/opengfw
  chmod +x deploy_opengfw.sh
  bash deploy_opengfw.sh
  ```

---

#### `manage_opengfw.sh`
- **用途**: 管理 OpenGFW 服务的交互式控制台

  - ✏️ 在线编辑规则
  - 🎛️ 服务启停管理
  - 🌍 更新 GeoIP 数据库
  - 📉 性能监控
  - 🗑️ 一键卸载
- **使用方法**:

#### `性能测试.sh`
- **用途**: 测试 OpenGFW 对服务器性能的影响
- **功能**:
  - 对比 OpenGFW 开启前后的 CPU、内存、网络延迟
  - 自动生成性能报告和优化建议
  - 支持基准测试和压力测试
- **使用方法**:
  ```bash
  bash /root/lxd-toolkit/server/opengfw/性能测试.sh
  ```
- **测试项目**:
  - CPU 使用率变化
  - 内存占用增加
  - 网络延迟影响
  - 网络吞吐量（需要 iperf3）

### 预设规则文件

#### `预设规则-轻量版.yaml`
- **用途**: 轻量级拦截规则
- **拦截协议**:
  - ✅ Shadowsocks / VMess
  - ✅ Trojan
  - ✅ Socks
- **性能影响**: < 5% CPU
- **推荐场景**:
  - 性能敏感的服务器
  - 新手测试
  - 低配置服务器

---

#### `预设规则-完全版.yaml`
- **用途**: 全面防护规则
- **拦截协议**:
  - ✅ Shadowsocks / VMess
  - ✅ Trojan
  - ✅ Socks
  - ✅ WireGuard
  - ✅ OpenVPN
  - ✅ BitTorrent
  - ✅ Ping0 娱乐库（域名过滤）
  - ✅ HTTP/HTTPS 代理
- **性能影响**: 10-20% CPU
- **推荐场景**:
  - 商业生产环境
  - 需要全面防护的服务器
  - 严格限制容器滥用

---

#### `预设规则-地域限制版.yaml`
- **用途**: 基于地域的拦截规则
- **拦截逻辑**:
  - 仅拦截来自**中国大陆**的代理连接
  - 全球拦截 BT 下载和特定域名
- **性能影响**: < 10% CPU
- **推荐场景**:
  - 有海外客户的服务器
  - 只限制国内客户滥用代理
  - 国际业务

## 🚀 快速开始

### 第一步：上传文件到服务器

```bash
# 方法 1：使用 SCP
scp -r server/opengfw root@你的服务器IP:/root/lxd-toolkit/server/

# 方法 2：在服务器上 Git 更新
cd /root/lxd-toolkit
git pull
```

### 第二步：运行部署脚本

```bash
cd /root/lxd-toolkit/server/opengfw
chmod +x *.sh
bash deploy_opengfw.sh
```

### 第三步：验证部署

```bash
# 查看服务状态
systemctl status opengfw

# 查看实时拦截日志
journalctl -u opengfw -f | grep "block"
```

### 第四步：日常管理

```bash
# 打开管理控制台
bash /etc/opengfw/manage_opengfw.sh
```

## 🛠️ 常用命令速查

```bash
# 服务管理
systemctl status opengfw          # 查看状态
systemctl start opengfw           # 启动
systemctl stop opengfw            # 停止
systemctl restart opengfw         # 重启

# 日志查看
journalctl -u opengfw -f          # 实时日志
journalctl -u opengfw -f | grep "block"   # 仅拦截日志

# 规则切换
cp /etc/opengfw/预设规则-轻量版.yaml /etc/opengfw/rules.yaml
systemctl restart opengfw

# 编辑规则
nano /etc/opengfw/rules.yaml
systemctl restart opengfw

# 管理控制台
bash /etc/opengfw/manage_opengfw.sh

# 性能测试
bash /root/lxd-toolkit/server/opengfw/性能测试.sh
```

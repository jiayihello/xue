二、上传到服务器
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法 1：使用 SCP（推荐）
-------------------------
在本地电脑运行：

  scp -r server/opengfw root@你的服务器IP:/root/lxd-toolkit/server/


方法 2：使用 Git（如果是 Git 仓库）
---------------------------------
在服务器上运行：

  cd /root/lxd-toolkit
  git pull


方法 3：使用 FTP/SFTP 工具
-------------------------
使用 WinSCP、FileZilla 等工具，将 opengfw 目录上传到：
  /root/lxd-toolkit/server/opengfw/

三、部署步骤（在服务器上操作）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. SSH 登录服务器
-----------------
  ssh root@你的服务器IP


2. 进入 OpenGFW 目录
--------------------
  cd /root/lxd-toolkit/server/opengfw


3. 赋予脚本执行权限
-------------------
  chmod +x *.sh


4. 运行一键部署脚本
-------------------
  bash deploy_opengfw.sh

  或使用快捷启动器：
  bash 一键部署OpenGFW.sh


5. 按提示完成部署
-----------------
  • 选择要拦截的协议（推荐选择 6 - 全部启用）
  • 选择是否启用地域限制（可选）
  • 等待自动下载和配置
  • 部署完成后自动启动服务

四、快速管理命令
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

打开管理控制台（推荐）
---------------------
  bash /etc/opengfw/manage_opengfw.sh

  功能包括：
    • 查看服务状态和日志
    • 切换规则文件
    • 查看拦截统计
    • 性能监控
    • 一键卸载


查看服务状态
-----------
  systemctl status opengfw


查看实时日志（拦截记录）
-----------------------
  journalctl -u opengfw -f | grep --color "block"


启动/停止/重启服务
-----------------
  systemctl start opengfw        # 启动
  systemctl stop opengfw         # 停止
  systemctl restart opengfw      # 重启


切换规则文件
-----------
  # 使用轻量版规则（性能优先）
  cp /etc/opengfw/预设规则-轻量版.yaml /etc/opengfw/rules.yaml
  systemctl restart opengfw

  # 使用完全版规则（全面防护）
  cp /etc/opengfw/预设规则-完全版.yaml /etc/opengfw/rules.yaml
  systemctl restart opengfw

  # 使用地域限制版（仅拦截中国大陆）
  cp /etc/opengfw/预设规则-地域限制版.yaml /etc/opengfw/rules.yaml
  systemctl restart opengfw


编辑自定义规则
-------------
  nano /etc/opengfw/rules.yaml
  systemctl restart opengfw      # 应用修改

六、规则文件选择建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌──────────────────┬────────────┬────────────┬────────────────┐
│ 规则版本         │ CPU 占用   │ 拦截范围   │ 推荐场景       │
├──────────────────┼────────────┼────────────┼────────────────┤
│ 轻量版           │ < 5%       │ 核心代理   │ 性能敏感服务器 │
│ 完全版           │ 10-20%     │ 全面防护   │ 商业生产环境   │
│ 地域限制版       │ < 10%      │ 仅中国大陆 │ 国际业务       │
└──────────────────┴────────────┴────────────┴────────────────┘


具体选择：
---------
• 如果服务器 CPU 资源紧张         → 使用"轻量版"
• 如果需要全面防护容器滥用         → 使用"完全版"
• 如果有海外客户，只限制国内滥用   → 使用"地域限制版"

七、性能优化建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果 CPU 占用过高：
------------------
1. 切换到轻量版规则
2. 编辑 /etc/opengfw/config.yaml
   workers:
     count: 4  # 减少工作线程（默认 8）
3. 关闭日志记录（在 rules.yaml 中设置 log: false）


如果内存占用过高：
-----------------
1. 编辑 /etc/opengfw/config.yaml
   workers:
     tcpTimeout: 3m  # 减少超时时间（默认 5m）
   io:
     queueSize: 1024  # 减少队列大小（默认 2048）


如果网络延迟增加明显：
---------------------
1. 使用轻量版规则
2. 增加工作线程数以提高并发处理

---------------------------

  选择 "9) 卸载 OpenGFW"


方法 2：手动卸载
---------------
  systemctl stop opengfw
  systemctl disable opengfw
  rm -f /etc/systemd/system/opengfw.service
  systemctl daemon-reload
  rm -rf /etc/opengfw

九、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 部署后容器网络不通？
A: 检查 iptables 规则是否冲突，运行：
   iptables -L -n | grep NFQUEUE
   如有问题，恢复备份：
   iptables-restore < /root/iptables_backup_*.rules


Q: 拦截不生效？
A: 1. 确认服务运行：systemctl status opengfw
   2. 查看日志：journalctl -u opengfw -f
   3. 检查规则文件：cat /etc/opengfw/rules.yaml


Q: CPU 占用过高？
A: 切换到轻量版规则：
   cp /etc/opengfw/预设规则-轻量版.yaml /etc/opengfw/rules.yaml
   systemctl restart opengfw


Q: 如何添加白名单？
A: 编辑 /etc/opengfw/rules.yaml，在文件开头添加：
   - name: allow trusted ip
     action: allow
     expr: string(ip.src) == "192.168.1.100"

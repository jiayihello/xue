# ✅ 检测脚本更新完成

## 📋 更新说明

已将检测脚本 `post_deployment_check.sh` 更新为适配**流量监控系统 V2 (iptables)**。

**更新时间:** 2025-10-30  
**文件:** `server/tools/diagnostic/post_deployment_check.sh`

---

## 🔧 主要更新内容

### **1. 修正 API 端口检测**
- **旧版:** 硬编码检查 8080 端口
- **新版:** 从 `app.ini` 读取 `HTTP_PORT`（默认 8060）
- **新增:** 使用 `/api/check` 端点而不是 `/api/ping`

### **2. 更新数据库检测**
- **旧版:** 检查 `flow_management.db`（旧版数据库）
- **新版:** 检查 `flow_management_v2.db`（V2 数据库）
- **新增:** 检测旧数据库并提示迁移

### **3. 更新 Systemd 服务检测**
**新增检测项：**
- ✅ `lxd-event-listener.service` - 容器事件监听
- ✅ `lxd-flow-collector.timer` - 流量收集（每分钟）
- ✅ `lxd-flow-limit-enforcer.timer` - 流量限制执行（每5分钟）
- ✅ `lxd-flow-reset-scheduler.timer` - 流量重置（每天凌晨1点）
- ✅ `lxd-periodic-sync.timer` - 定期同步（每小时）
- ✅ `lxd-boot-restore.service` - 启动恢复

**移除检测项：**
- ❌ `lxd-flow-continuity.service` - 旧服务，已废弃
- ❌ Cron 定时任务检查 - 现在使用 systemd timers

### **4. 新增 iptables 规则检测 (V2)**
- ✅ 检测流量统计规则
- ✅ 检测 NAT MASQUERADE 规则
- ✅ 检测 iptables 元数据文件 (`iptables_rules.json`)

### **5. 增强 IPv6 检测**
- ✅ 识别 IPv6-Only 模式
- ✅ 识别双栈模式
- ✅ 检测 IPv6 前缀配置
- ✅ 检测 IPv6 分配记录

### **6. 更新日志文件检测**
**新版日志文件：**
- `lxd_events.log` - 事件监听器日志
- `flow_collector.log` - 流量收集器日志
- `iptables_manager.log` - iptables 管理器日志

**旧版日志（已移除）：**
- `flow_continuity_daemon.log`
- `flow_limit_enforcer.log` (旧版)

### **7. 新增性能优化检测**
- ✅ 检测文件锁机制（V2 性能优化）
- ✅ 检测 filelock 库
- ✅ 日志文件大小警告（超过100MB）

### **8. 修正路径问题**
- **旧版:** 假设在 server 根目录运行
- **新版:** 正确处理从 `tools/diagnostic/` 目录运行，自动导航到 server 目录

## 🚀 使用方法

### 方式1：直接使用二进制（推荐，最快）

```bash
cd LinuxTools-main
sudo bash lxdimages.sh

# 安装完成后使用
lxdimages alpine 3.22 -add ssh -name alpine322
```

**优点**：
- ⚡ 最快速
- ✅ 无需编译环境
- ✅ 即装即用

### 方式2：从源代码编译（最安全）

```bash
cd LinuxTools-main/lxdimages-bin

# 安装 Go 编译器（如果没有）
sudo apt install golang-go

# 编译
bash build.sh

# 或手动编译
go build -o lxdimages-amd64 main.go

# 然后安装
cd ..
sudo bash lxdimages.sh --force
```

**优点**：
- 🔒 最安全（自己编译）
- ✅ 可以审计源代码
- ✅ 确保无后门

### 方式3：修改源码后编译（最灵活）

```bash
cd LinuxTools-main/lxdimages-bin

# 1. 修改源代码
vim main.go
# 或
vim tools/ssh.go

# 2. 编译自定义版本
go build -o lxdimages-amd64 main.go

# 3. 安装
cd ..
sudo bash lxdimages.sh --force

# 4. 使用你的自定义版本
lxdimages --version
```

**优点**：
- 🎨 完全自定义
- ✅ 添加新功能
- ✅ 针对性优化
- ✅ 支持新发行版

## 🎨 自定义示例

### 示例1：添加新的工具集

编辑 `tools/ssh.go`，添加 Docker 安装：

```go
package tools

// 原有的 SSH 函数
func InstallSSH() error {
    // ...
}

// 新增 Docker 安装
func InstallDocker() error {
    cmd := exec.Command("bash", "-c", `
        apt-get update
        apt-get install -y docker.io
        systemctl enable docker
        systemctl start docker
    `)
    return cmd.Run()
}
```

然后在 `main.go` 中调用：

```go
if tools == "ssh" {
    InstallSSH()
} else if tools == "docker" {
    InstallDocker()
}
```

重新编译：
```bash
go build -o lxdimages-amd64 main.go
```

### 示例2：优化二进制大小

```bash
# 使用优化选项编译
go build -ldflags="-s -w" -o lxdimages-amd64 main.go

# 对比大小
# 原始: 8.88 MB
# 优化后: ~6.5 MB（减少约 27%）
```

## 🔍 版本检测逻辑

### 检测步骤

1. **读取 /etc/os-release 文件**
   ```bash
   ID="debian"
   VERSION_ID="12"
   ```

2. **判断系统类型**
   - Debian → 根据 VERSION_ID 确定 Python 版本
   - Ubuntu → 自动检测 Python 版本
   - 其他 → 自动检测 Python 版本

3. **自动检测 Python 版本**（作为后备方案）
   ```bash
   python3 --version | grep -oP '\d+\.\d+'
   # 输出: 3.11
   ```

4. **构造文件路径**
   ```bash
   /usr/lib/python${python_version}/EXTERNALLY-MANAGED
   ```

## 💡 特殊处理

### 1. iptables-persistent 交互

**问题**：安装 `iptables-persistent` 时会弹出交互提示

**解决方案**：
```bash
DEBIAN_FRONTEND=noninteractive apt-get install -y iptables-persistent
```

**效果**：
- ✅ 自动选择默认值（no）
- ✅ 无需手动干预
- ✅ 静默安装

### 2. Python EXTERNALLY-MANAGED 文件

**问题**：Python 3.11+ 的系统包管理限制

**解决方案**：删除限制文件
```bash
rm /usr/lib/python3.11/EXTERNALLY-MANAGED
```

**效果**：
- ✅ 允许使用 `pip install` 安装全局包
- ✅ 不再提示 "externally-managed-environment"
- ✅ 兼容旧版行为

## 🔧 代码实现

### 核心函数

```bash
prepare_system_for_lxd() {
    msg_info "--- 准备系统环境 ---"
    
    # 1. 安装依赖（非交互式）
    DEBIAN_FRONTEND=noninteractive apt-get install -y \
        curl wget git iptables iptables-persistent \
        python3 python3-pip sqlite3 cron
    
    # 2. 检测系统版本
    source /etc/os-release
    
    # 3. 确定 Python 版本
    if [[ "$ID" == "debian" ]]; then
        case "$VERSION_ID" in
            "12") python_version="3.11" ;;
            "13") python_version="3.13" ;;
            *) python_version=$(python3 --version | grep -oP '\d+\.\d+') ;;
        esac
    fi
    
    # 4. 删除 EXTERNALLY-MANAGED 文件
    rm -f "/usr/lib/python${python_version}/EXTERNALLY-MANAGED"
}
```

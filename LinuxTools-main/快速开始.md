# 🚀 LinuxTools 快速开始指南

## 📋 工具集概览

LinuxTools 包含两个主要工具：

| 工具 | 功能 | 离线可用 | 源代码 |
|------|------|---------|--------|
| **linuxtools.sh** | LXD环境管理 + 虚拟内存 | ✅ 是 | ✅ 是 |
| **lxdimages** | 自定义镜像构建 | ✅ 是 | ✅ 是 |

---

## ⚡ 5分钟快速上手

### 第一步：安装 LXD

```bash
cd LinuxTools-main
sudo bash linuxtools.sh

# 在菜单中选择：
# 1) 安装或检查 LXD 环境
```

**大约需要**: 2-3 分钟

---

### 第二步：安装 lxdimages 工具

```bash
# 仍在 LinuxTools-main 目录下
sudo bash lxdimages.sh
```

**大约需要**: 10 秒（本地复制）

---

### 第三步：构建第一个镜像

```bash
# 构建 Alpine Linux 镜像
lxdimages alpine 3.22 -add ssh -name alpine322
```

**大约需要**: 1-2 分钟

---

### 第四步：创建容器

```bash
# 使用刚构建的镜像创建容器
lxc launch alpine322 my-first-container

# 进入容器
lxc exec my-first-container -- /bin/sh
```

**大约需要**: 5 秒

## 🎯 完整工作流示例

### 场景1：快速测试环境

```bash
# === 总耗时约 5 分钟 ===

# 1. 安装 LXD（2-3分钟）
cd LinuxTools-main

lxdimages alpine 3.22 -add ssh -name alpine322

# 4. 创建容器（5秒）

# 5. 进入容器
lxc exec test-container -- /bin/sh

```

```bash

# 1. 初始化 LXD 环境
cd LinuxTools-main

菜单操作：

```

### 场景3：内网部署

```bash
# === 完全离线，总耗时约 5 分钟 ===

# 1. 将 LinuxTools-main 目录复制到内网服务器
scp -r LinuxTools-main root@内网IP:/root/

# 2. 在内网服务器上操作
ssh root@内网IP
cd /root/LinuxTools-main

# 3. 安装 LXD（完全离线）
sudo bash linuxtools.sh
# 选择 1) 安装 LXD

# 4. 安装 lxdimages（完全离线）
sudo bash lxdimages.sh

# 5. 构建镜像（需要网络下载基础镜像）
# 注意：构建镜像时需要从 LXD 官方下载基础镜像
lxdimages alpine 3.22 -add ssh -name alpine322

# === 完成！===
```

## 📚 常用命令速查

### linuxtools.sh 菜单

```bash
sudo bash linuxtools.sh

菜单选项：
1) 安装或检查 LXD 环境          ← 首次必选
2) 下载 Alpine 3.19 镜像
3) 下载 Debian 12 镜像
4) 备份所有本地 LXD 镜像
5) 从备份恢复 LXD 镜像
6) 创建 BTRFS 存储池（从文件）
7) 列出本地 LXD 镜像
8) 安装并配置 ZRAM              ← 推荐
9) 移除 ZRAM
10) 添加 Swap 文件
11) 移除 Swap 文件
```

---

### lxdimages 命令

```bash
# 基本语法
lxdimages [发行版] [版本] -add [工具] -name [镜像名]

# 常用示例
lxdimages alpine 3.22 -add ssh -name alpine322
lxdimages debian bookworm -add ssh -name debian12
lxdimages ubuntu jammy -add ssh -name ubuntu2204
lxdimages centos 9-Stream -add ssh -name centos9
lxdimages fedora 41 -add ssh -name fedora41
```

---

### LXD 基本命令

```bash
# 查看镜像列表
lxc image list

# 创建容器
lxc launch [镜像名] [容器名]

# 列出容器
lxc list

# 启动/停止容器
lxc start [容器名]
lxc stop [容器名]

# 进入容器
lxc exec [容器名] -- /bin/sh
lxc exec [容器名] -- /bin/bash

# 删除容器
lxc delete [容器名] --force

# 删除镜像
lxc image delete [镜像名]
```

## 🔧 常见问题快速解决

### Q1: 提示 LXD 未安装？

```bash
# 解决方法：先安装 LXD
cd LinuxTools-main
sudo bash linuxtools.sh
# 选择 1) 安装 LXD
```

### Q2: lxdimages 命令找不到？

```bash
# 解决方法：重新安装
cd LinuxTools-main
sudo bash lxdimages.sh --force

# 或添加到 PATH
export PATH=$PATH:/usr/local/bin
```

### Q3: 构建镜像失败？

```bash
# 检查 LXD 是否正常
lxd --version
lxc list

# 检查网络连接
ping -c 1 images.linuxcontainers.org

# 查看详细错误
lxdimages alpine 3.22 -add ssh -name alpine322
```

### Q4: 容器创建失败？

```bash
# 检查镜像是否存在
lxc image list | grep alpine322

# 查看 LXD 日志
sudo journalctl -u snap.lxd.daemon -n 50
```

### Q5: 想从源代码编译？

```bash
# 安装 Go 编译器
sudo apt install golang-go

# 编译
cd LinuxTools-main/lxdimages-bin
bash build.sh

# 重新安装
cd ..
sudo bash lxdimages.sh --force
```

## 💡 高级用法

### 批量构建多个镜像

```bash
#!/bin/bash
# build-all-images.sh

cd LinuxTools-main

# 后台并行构建
lxdimages alpine 3.22 -add ssh -name alpine322 &
lxdimages alpine 3.21 -add ssh -name alpine321 &
lxdimages debian bookworm -add ssh -name debian12 &
lxdimages ubuntu jammy -add ssh -name ubuntu2204 &

# 等待所有构建完成
wait

echo "所有镜像构建完成！"
lxc image list
```

### 自动备份脚本

```bash
#!/bin/bash
# backup-images.sh

# 备份镜像
cd LinuxTools-main
echo "4" | sudo bash linuxtools.sh

# 可选：压缩备份
tar -czf lxd-images-backup-$(date +%Y%m%d).tar.gz /root/lxc_image_backups/

echo "备份完成！"
```

### 定期清理脚本

```bash
#!/bin/bash
# cleanup.sh

# 删除已停止的容器
lxc list --format csv | grep STOPPED | cut -d, -f1 | xargs -I {} lxc delete {}

# 删除未使用的镜像（谨慎！）
# lxc image list --format csv | ...

echo "清理完成！"
```

## 🎯 推荐配置

### 最小配置

- CPU: 2 核心
- 内存: 2 GB
- 硬盘: 20 GB
- 网络: 可选

**适合**: 测试环境、学习用途

### 推荐配置

- CPU: 4+ 核心
- 内存: 8+ GB
- 硬盘: 100+ GB SSD
- 网络: 稳定连接

**适合**: 生产环境、多容器

- CPU: 8+ 核心
- 内存: 16+ GB
- 硬盘: 500+ GB NVMe
- 网络: 千兆+
- 启用 ZRAM

**适合**: 大规模部署

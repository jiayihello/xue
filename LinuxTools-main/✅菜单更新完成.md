## 📋 新菜单结构

```
=========================================
    LXD 容器管理工具箱 (整合版)        
=========================================

--- LXD 环境 ---
  1) 安装或检查 LXD 环境
  2) 创建 BTRFS 存储池（从文件）

--- 镜像管理 ---
  3) 安装 lxdimages 镜像构建工具
  4) 构建自定义镜像
  5) 备份所有本地 LXD 镜像
  6) 列出本地 LXD 镜像

--- 虚拟内存管理 ---
  7) 安装并配置 ZRAM (内存压缩, 推荐)
  8) 移除 ZRAM
  9) 添加 Swap 文件 (基于硬盘)
 10) 移除 Swap 文件

  ---------------------------------------
  0) 退出脚本
=========================================
```

## 🔧 主要变更

### 1. ❌ 删除的功能

- `2) 下载 Alpine 3.19 镜像` - 已删除
- `3) 下载 Debian 12 镜像` - 已删除
- `download_alpine_image()` 函数 - 已删除
- `download_debian_image()` 函数 - 已删除

### 2. ✅ 新增的功能

**新增函数**：

1. **install_lxdimages_tool()** - 安装 lxdimages 工具
   - 检查是否已安装
   - 调用本地 `lxdimages.sh` 脚本
   - 自动化安装流程

2. **build_custom_images()** - 构建自定义镜像
   - 支持多选镜像
   - 快捷选项（3个常用镜像）
   - 完整列表（11个镜像）
   - 自动验证导入
   - 自动清理临时文件
   - 显示详细结果统计

**新增菜单选项**：

- `3) 安装 lxdimages 镜像构建工具`
- `4) 构建自定义镜像`

### 3. 🔄 调整的功能

选项编号调整：
- `4) 备份镜像` → `5) 备份镜像`
- `5) 恢复镜像` → 已移除
- `6) 创建存储池` → `2) 创建存储池`
- `7) 列出镜像` → `6) 列出镜像`
- `8-11) 虚拟内存` → `7-10) 虚拟内存`

## 🎯 功能说明

### 选项 3：安装 lxdimages 工具

**功能**：
- 运行 `lxdimages.sh` 安装脚本
- 从本地 `lxdimages-bin/` 复制二进制文件
- 安装到 `/usr/local/bin/lxdimages`

**特点**：
- ✅ 检查是否已安装
- ✅ 完全离线可用
- ✅ 安装成功后自动进入选项 4

## 📝 使用示例

### 场景 1：首次使用

```bash
# 1. 启动脚本
sudo bash linuxtools.sh

# 2. 安装 LXD
选择: 1

# 3. 安装 lxdimages 工具
选择: 3
# → 自动安装工具
# → 自动进入镜像构建界面

# 4. 选择镜像
输入: 1 3
# → 构建 Debian 12 和 Alpine 3.22

# 完成！
```

### 场景 2：构建多个镜像

```bash
# 1. 进入脚本
sudo bash linuxtools.sh

# 2. 选择构建镜像
选择: 4

# 3. 查看完整列表
输入: [回车]

# 4. 选择多个镜像
输入: 2 4 9 11
# → 构建 Debian 12, Ubuntu 22.04, Alpine 3.22, Fedora 41

# 完成！
```
